## 🌐 Deploy to Netlify (3 Easy Steps)

### Step 1: Login to Netlify

Go to: **https://app.netlify.com/start**

- If you don't have an account, create one (free)
- If your friend already has the site, use their account

### Step 2: Deploy from GitHub

1. Click **"Add new site"** → **"Import an existing project"**

2. Click **"Deploy with GitHub"**

3. Authorize Netlify to access your GitHub

4. Search for and select: **Nabilhassan12345/flowsentinel**

5. Configure build settings:
   ```
   Branch to deploy: main
   Build command: npm run build
   Publish directory: public
   ```

6. Click **"Deploy site"**

### Step 3: Set Site Name

1. After deployment, go to **Site settings**

2. Click **"Change site name"**

3. Enter: **flowsentinel**

4. Save

**Your site will be live at:** https://flowsentinel.netlify.app
