## 🎯 Deploy Using Netlify Dashboard (5 Minutes)

### Step 1: Go to Netlify

1. Open browser and go to: **https://app.netlify.com**
2. Login with your account (or your friend's account that has flowsentinel)

### Step 2: Import from GitHub

If site already exists:
1. Go to **Sites** → Find "**flowsentinel**"
2. Click on it
3. Go to **Deploys** tab
4. Click **"Trigger deploy"** → **"Deploy site"**
5. Done! ✅

If creating new site:
1. Click **"Add new site"** → **"Import an existing project"**
2. Choose **GitHub**
3. Select repository: **Nabilhassan12345/flowsentinel**
4. Configure:
   - **Branch to deploy:** `main`
   - **Build command:** `npm run build`
   - **Publish directory:** `public`
5. Click **"Deploy site"**

### Step 3: Set Site Name

1. Go to **Site settings** → **General** → **Site details**
2. Click **"Change site name"**
3. Enter: **flowsentinel**
4. Click **"Save"**

Your site will be at: **https://flowsentinel.netlify.app** ✅

## 🐛 Troubleshooting

### Issue: Site name "flowsentinel" is taken

**Option 1:** Use existing site
- If your friend already has flowsentinel.netlify.app
- Just trigger a new deploy from that site

**Option 2:** Use different name
- Try: flowsentinel-ai, flowsentinel-ibm, flowsentinel-demo
- Your site will be at: https://yourname.netlify.app

### Issue: Build fails

The build is very simple (static HTML), but if it fails:
1. Go to **Site settings** → **Build & deploy** → **Build settings**
2. Change **Build command** to: `echo "Static site"`
3. Make sure **Publish directory** is: `public`
4. Redeploy

## 📱 Alternative: Deploy via Netlify Drop
